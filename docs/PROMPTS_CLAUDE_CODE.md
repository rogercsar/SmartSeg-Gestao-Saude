# Comandos prontos para o Claude Code (VS Code)

Use **um módulo por vez**, em uma ramificação (branch) própria. Sempre peça o **plano antes** do código.

## Antes do primeiro módulo (uma vez)

```
Leia o CLAUDE.md e analise este repositório. Complete a seção 'Arquitetura do sistema real' do CLAUDE.md com o que encontrar (pastas, padrões de rota, autenticação, permissões, multi-cliente, componentes de tela, testes, como rodar). Não altere código. Mostre o resultado para eu revisar.
```

## Módulo 1 — Organização, perfis e permissões

```
Crie a branch modulo-organizacao-permissoes.
Leia docs/modulos/01-organizacao-permissoes.md e os arquivos de referência citados nele (pasta migracao/referencia-base44, só para consulta).
1) Mapeie as tabelas do módulo para as tabelas que já existem neste sistema (docs/MAPA_TABELAS.md) e proponha as alterações no schema.prisma e a migração — só o que falta, sem duplicar.
2) Porte as regras de dominio/ citadas para TypeScript tipado no padrão deste projeto, mantendo os testes de testes/dominio.test.ts que se aplicam (os resultados precisam ser iguais).
3) Implemente backend e telas no padrão deste projeto, com as permissões verificadas no backend.
Mostre o PLANO e espere minha aprovação antes de escrever código. Ao final: rode lint, typecheck e testes, e abra o pull request com o resumo e o roteiro de validação do módulo.
```
